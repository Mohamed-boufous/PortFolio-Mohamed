- **Home** — Introduction, resume download, interactive profile picture with ASCII art effect
- **Skills** — Technical skills showcase with rolling gallery and skill cards

## 🚀 Features

- ⚡ Built with **Vite + React** for blazing-fast performance
- 🌙 **Dark/Light mode** with animated stars and ripple grid backgrounds
- 🌍 **Bilingual** (English / French) with language context
- 🎨 **Premium UI** with glassmorphism, micro-animations, and 3D elements
- 📱 **Fully responsive** design for all devices
- 🔍 **SEO optimized** with meta tags, JSON-LD structured data, sitemap, and Open Graph
